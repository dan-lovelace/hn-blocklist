A bookmarklet for removing unwanted posts from Hacker News. Currently configured
to target AI-related posts.

[View the source code](https://github.com/dan-lovelace/hn-blocklist/blob/main/src/bookmarklet.js)

## Installation

1. Visit
   [https://dan-lovelace.github.io/hn-blocklist/](https://dan-lovelace.github.io/hn-blocklist/)
