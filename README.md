# HN Blocklist

A bookmarklet for removing unwanted posts from Hacker News.

## Installation

1. Create a new Bookmark by hand or drag this link to your Bookmarks:
   <a href="">HN ⛔</a>
2. Right click it and choose "Edit bookmark..."
3. Click the "Copy" button on the right side of this snippet:
   <!-- BOOKMARKLET-START -->
   <!-- BOOKMARKLET-END -->
4. Paste the snippet into the bookmark's URL field and save
5. Click the bookmark any time you visit Hacker News
